# Portfolio

Portfolio website by Morten Fredslund Løkke.

Plain HTML, CSS and JS in `site/`, deployed with Netlify on every push to `main`.

## Edit locally

1. Clone: `git clone https://github.com/MortFredLoek/portfolio.git`
2. Open the folder in VS Code and install the recommended extensions when asked.
3. Right click `site/index.html` → "Open with Live Server" to preview.
4. Commit and push. Netlify deploys `main` automatically; other branches get preview URLs
   through pull requests.

See `CLAUDE.md` for the structure, design rules and the optional Are.na sync.
